# Himawari_Geo2Pixelpos

## Overview
Himawari_Geo2Pixelpos is a tool designed to convert geographical coordinates into pixel positions on Himawari satellite images. This tool is useful for researchers and meteorologists who need to map specific geographic locations onto satellite imagery for analysis and visualization.

## Features
- Convert latitude and longitude to pixel positions.
- Support for various Himawari satellite image resolutions.
- Easy integration with existing data processing pipelines.
